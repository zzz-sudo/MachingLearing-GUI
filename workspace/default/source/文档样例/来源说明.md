# 文档样例来源

输入格式: PDF、XLSX、CSV 和 ZIP。输出类型: 用于解析、编码识别和导出的本地测试输入。

`Scikit-learn机器学习工具论文.pdf` 来源于 Journal of Machine Learning Research 的公开论文页面:

https://jmlr.org/papers/volume12/pedregosa11a/pedregosa11a.html

论文页面明确说明 Scikit-learn 使用简化 BSD 许可证, 适合学术和商业场景。该文件仅用于本项目的 PDF 解析测试, 下载日期以 Git 提交记录为准。

English comment: This sample is an open-access JMLR paper used to test digital PDF parsing and export.

`销售汇总表.pdf` 由 `scripts/build_sample_table_pdf.py` 确定性生成, 采用 CC0-1.0, 用于验证 PDF 表格识别。其中文字和数值均为测试数据, 不代表真实业务记录。
